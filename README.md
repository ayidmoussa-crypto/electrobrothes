# ⚡ ElectroBrothers — متجر إلكترونيات بالدفع عند الاستلام

متجر إلكتروني مغربي للسماعات والساعات الذكية والشواحن والباوربانك، يعمل بنظام **الدفع نقداً عند الاستلام فقط**، بالعربية (افتراضياً، من اليمين إلى اليسار) والإنجليزية.

**ما يتضمنه المشروع:**

- **واجهة المتجر:** الرئيسية، الأقسام بالفلاتر والترتيب، صفحة المنتج (معرض صور، خيارات، مواصفات، تقييمات)، البحث الفوري، مقارنة حتى 3 أجهزة، السلة، الطلب في صفحة واحدة، صفحة الشكر، تتبع الطلب، والصفحات القانونية.
- **نظام الدفع عند الاستلام:** نموذج طلب بدون حساب (أيضاً داخل صفحة المنتج)، رسوم توصيل حسب المدينة، توصيل مجاني فوق حد معيّن، كوبونات، وحماية من الطلبات الوهمية.
- **لوحة التحكم:** الإحصائيات، الطلبات وتغيير حالتها، تصدير CSV لشركة التوصيل، المنتجات، الأقسام، الماركات، المدن، الكوبونات، القائمة السوداء، والإعدادات.
- **التسويق والإشعارات:** إشعار بالبريد الإلكتروني عند كل طلب، زر واتساب، وبيكسلات Meta و GA4 و TikTok.
- **SEO وإمكانية الوصول:** Schema.org، خريطة الموقع، روابط hreflang، ومعايير WCAG AA.

## 1. التقنيات

| الجزء | التقنية |
|---|---|
| الإطار | Next.js 16 (App Router, Cache Components) + React 19 + TypeScript |
| التصميم | Tailwind CSS v4 — كل الألوان كـ Design Tokens في `src/app/globals.css` |
| قاعدة البيانات | PostgreSQL على Neon + Prisma 7 |
| اللغات | next-intl (العربية `/`، الإنجليزية `/en`) |
| التحقق من المدخلات | Zod (على الخادم) |
| البريد | Nodemailer (أي خادم SMTP) |
| الصور | Cloudinary (اختياري) أو روابط مباشرة |

**المتطلبات:** Node.js 20 أو أحدث، وحساب مجاني على [Neon](https://neon.tech).

## 2. التثبيت والتشغيل محلياً

### أ. تثبيت الحزم
```bash
npm install
```

### ب. قاعدة البيانات (Neon)

**الطريقة الأسهل: أداة Neon:**
```bash
npm i -g neon
neon login
neon init -y --agent claude-code --region-id aws-eu-central-1 --project-name electrobrothers
neon checkout dev --create
```
الأمر الأخير ينشئ فرع `dev` للتطوير، ويكتب روابط الاتصال في `.env.local`.

**أو من موقع Neon:**
1. أنشئ مشروعاً في منطقة **AWS Europe (Frankfurt)**.
2. أنشئ فرعاً اسمه `dev`.
3. من زر **Connect**، انسخ الرابطين:
   - الرابط مع **Connection pooling** يوضع في `DATABASE_URL`.
   - الرابط بدونه يوضع في `DATABASE_URL_UNPOOLED`.
4. ضعهما في ملف `.env.local`.

> ⚠️ **غيّر `sslmode=require` إلى `sslmode=verify-full`** في الرابطين، وإلا ستظهر رسالة تحذير من مكتبة `pg`. أداة Neon تعيد كتابة `require` بعد كل `neon checkout` أو `neon env pull`، فأعد التعديل بعدها.

### ج. ملف الإعدادات
انسخ `.env.example` إلى `.env` واملأ `SESSION_SECRET` (إلزامي). كل متغير مشروح داخل الملف.
```bash
node -e "console.log(require('crypto').randomBytes(48).toString('base64url'))"
```

### د. إنشاء الجداول والبيانات التجريبية ثم التشغيل
```bash
npm run setup && npm run dev
```
- `setup` ينشئ الجداول ويضيف بيانات تجريبية: 24 منتجاً، 5 أقسام، 30 مدينة، وكوبونين.
- يمكن إعادة تشغيله بأمان. لكنه **يرفض العمل على فرع production**.
- افتح المتجر على http://localhost:3000.

> في Windows PowerShell 5.1 لا يعمل `&&`. شغّل الأمرين كل واحد على حدة.

### هـ. حساب المدير
```bash
npm run admin:create -- --email you@example.com --password "كلمة سر من 12 حرفاً على الأقل" --name "اسمك"
```
ثم ادخل إلى http://localhost:3000/admin

### الأوامر

## 3. استعمال لوحة التحكم (`/admin`)

### إضافة منتج
**المنتجات ← منتج جديد**، ثم:
1. **المعلومات الأساسية:**
   - الاسم والوصف باللغتين.
   - الرابط (slug): يُملأ تلقائياً من الاسم الإنجليزي.
   - القسم، الماركة، ومدة الضمان.
2. **الصور:**
   - ارفعها مباشرة إذا أضفت مفاتيح Cloudinary.
   - أو الصق روابطها (`https://…`).
   - الصورة الأولى هي الرئيسية، ويمكن تغيير الترتيب بالأسهم.
3. **الخيارات:** سطر لكل لون أو سعة، فيه:
   - رمز SKU (فريد)، والسعر بالدرهم، والسعر قبل التخفيض (اختياري)، والمخزون.
   - الخيار الأول هو الافتراضي.
4. **المواصفات:** المفاتيح `ram` و `storage` و `screen` و `cpu` تظهر كفلاتر في صفحات الأقسام. أدخل لها **قيمة رقمية**، مثل 8 أو 256 أو 6.1.
5. **العرض المحدود (اختياري):** حدّد تاريخ النهاية، فيظهر المنتج مع عدّاد تنازلي في الصفحة الرئيسية.

التعديلات تظهر في المتجر فوراً.

### معالجة الطلبات
1. يصلك طلب جديد في لوحة التحكم، وبالبريد إن أعددت SMTP.
2. **اتصل بالزبون:** زر «اتصال»، أو زر «تأكيد عبر واتساب» برسالة جاهزة.
3. غيّر حالة الطلب:
   - **جديد ← مؤكَّد:** يُخصم المخزون تلقائياً.
   - **مؤكَّد ← قيد الشحن ← مُسلَّم.**
   - **ملغى أو مُرجَع:** يُعاد المخزون تلقائياً.
4. كل تغيير يُسجَّل في سجل الطلب، مع اسم من قام به وملاحظته.
5. **تصدير CSV لشركة التوصيل:**
   - يمكنك تصفية الطلبات أولاً، مثلاً الحالة «مؤكَّد».
   - الملف يُفتح مباشرة في Excel بالعربية.
   - فيه المبلغ الذي يجب تحصيله من كل زبون.

### الحماية من الطلبات الوهمية
كل طلب يحصل على **درجة خطورة** تظهر في لوحة التحكم.
- **ما يرفع الدرجة:** رقم مكرر خلال 24 ساعة، ملء سريع جداً للنموذج، أو طلبات كثيرة من نفس الجهاز.
- **ما يُرفض مباشرة:** الأرقام الموجودة في **القائمة السوداء**، والروبوتات (عبر حقل مخفي فخّ).
- **حدود:** 5 طلبات في الساعة لكل عنوان IP.
- **Cloudflare Turnstile (اختياري ومجاني):** يتفعل بإضافة مفاتيحه إلى `.env`.

### الإعدادات
في **الإعدادات** يمكنك تعديل:
- حد التوصيل المجاني.
- رقم واتساب: يُظهر الزر العائم وزر «أكّد طلبك عبر واتساب».
- البريد الإلكتروني لإشعارات الطلبات الجديدة.

ورسوم التوصيل ومدته لكل مدينة تُعدَّل من **المدن والتوصيل**.

---

### المساعد الذكي
الزر الأصفر العائم في كل صفحات اللوحة يفتح محادثة تقبل النص والصور (بالدارجة أو العربية أو الفرنسية).
- **يتطلب:** `ANTHROPIC_API_KEY` في `.env.local` أو `.env`. الاتصال بـ Claude من الخادم فقط.
- **لا يغيّر شيئاً وحده:** يقترح، وتظهر بطاقة، ولا يُنفَّذ شيء قبل الضغط على «تأكيد». الاقتراح يسقط بعد 24 ساعة.
- **السجل والتراجع:** **سجل المساعد** (`/admin/assistant`). حركات المخزون تظهر أيضاً في سجل حركات المنتج.
- **النماذج:** `claude-haiku-5-5` للمهام البسيطة، و`claude-sonnet-5-5` للتحليل.
- **السقف الشهري:** من **الإعدادات**، بالدولار. عند بلوغه يتوقف المساعد.
- **سعر الشراء المذكور في المحادثة** يُسجَّل في حركة المخزون فقط، ولا يغيّر السعر المحفوظ للمنتج.
- **التعرّف من الصورة** يحتاج صور منتجات حقيقية (JPG أو PNG أو WebP). الرسومات المؤقتة (SVG) لا يمكن مقارنتها.
- **صورة المسودة** تُرفع إلى Cloudinary عند الضغط على «تأكيد». بدون مفاتيح Cloudinary تُنشأ المسودة بدون صورة.

## 4. تغيير الألوان والهوية

جميع الألوان معرّفة **في مكان واحد**: `src/app/globals.css`، داخل `@theme`.
- **لتغيير لون:** عدّل قيمة HEX هناك فقط، فيتغير في كل المتجر ولوحة التحكم. مثلاً، الأصفر الأساسي هو `--color-yellow-500`.
- **ممنوع كتابة HEX داخل المكوّنات:** قاعدة ESLint ترفض ذلك (`npm run lint`).
- ألوان Tailwind الافتراضية (الأزرق، الرماديات الباردة…) معطّلة عمداً.
- قواعد الهوية الكاملة (نسب الألوان، التباين، استعمال الأصفر) موجودة في `CLAUDE.md`.

**الخطوط:** Inter (للحروف اللاتينية والأرقام) و IBM Plex Sans Arabic، في `src/app/fonts.ts`.

**الشعار:**
- النسخة المتجهية في `public/brand/logo.svg` و `src/components/brand/Logo.tsx`.
- أيقونة المتصفح في `src/app/icon.svg`.
- الأصل في `brand/logobrand.pdf`.

## 5. الخدمات الاختيارية (`.env`)

| الخدمة | المتغيرات | ملاحظات |
|---|---|---|
| البريد (SMTP) | `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS`, `SMTP_FROM` | Gmail: `smtp.gmail.com:587` مع «كلمة سر التطبيقات». Brevo: `smtp-relay.brevo.com:587` (خطة مجانية) |
| رفع الصور | `CLOUDINARY_CLOUD_NAME`, `CLOUDINARY_API_KEY`, `CLOUDINARY_API_SECRET` | خطة Cloudinary المجانية كافية للبداية |
| مكافحة الروبوتات | `NEXT_PUBLIC_TURNSTILE_SITE_KEY`, `TURNSTILE_SECRET_KEY` | من لوحة Cloudflare ← Turnstile |
| Meta Pixel | `NEXT_PUBLIC_META_PIXEL_ID` | الأحداث: ViewContent, AddToCart, InitiateCheckout, Purchase |
| Google Analytics 4 | `NEXT_PUBLIC_GA4_ID` | view_item, add_to_cart, begin_checkout, purchase |
| TikTok Pixel | `NEXT_PUBLIC_TIKTOK_PIXEL_ID` | ViewContent, AddToCart, InitiateCheckout, CompletePayment |
| رابط المتجر | `NEXT_PUBLIC_SITE_URL` | **إلزامي في الإنتاج**: تُبنى عليه الروابط في SEO وفي رسائل البريد |

كل خدمة لا تُضاف مفاتيحها تبقى معطّلة، دون أن يتعطل المتجر.

## 6. النشر

### أ. على Vercel (الأسهل)
1. ارفع المشروع إلى GitHub، ثم استورده في Vercel.
2. **Build Command:** `npm run build:prod` (يطبّق الـ migrations قبل البناء).
3. في **Environment Variables**، أضف:
   - روابط فرع **production** من Neon: `DATABASE_URL` و `DATABASE_URL_UNPOOLED` و `NEON_BRANCH=production`.
   - `SESSION_SECRET` جديد.
   - `NEXT_PUBLIC_SITE_URL` (رابط الدومين الحقيقي).
   - مفاتيح الخدمات الاختيارية التي تريدها.
4. اربط الدومين ديالك من **Settings ← Domains**.
5. أنشئ حساب المدير على قاعدة الإنتاج من جهازك، بعد وضع روابط production مؤقتاً في `.env.local`:
   ```bash
   npm run admin:create -- --email you@example.com --password "..."
   ```
6. أضف منتجاتك الحقيقية من لوحة التحكم. لا تشغّل `setup`، فالبيانات التجريبية ممنوعة على فرع production.

### ب. على خادم VPS (Ubuntu)
```bash
# على الخادم: Node 20 و git و nginx
git clone <repo> electrobrothers && cd electrobrothers
npm ci
cp .env.example .env    # املأ القيم (روابط production، SESSION_SECRET، NEXT_PUBLIC_SITE_URL…)
npm run build:prod
npm i -g pm2
pm2 start npm --name electrobrothers -- start -- -p 3000
pm2 save && pm2 startup
```
- **nginx:** اضبطه كـ reverse proxy نحو `localhost:3000`.
- **HTTPS:** فعّله مجاناً بـ `certbot --nginx`.
- **عند كل تحديث:**
  ```bash
  git pull && npm ci && npm run build:prod && pm2 restart electrobrothers
  ```

## 8. الجودة والأمان

- **الاختبارات:** 42 اختباراً. تغطي حساب الأسعار والكوبونات، أرقام الهاتف المغربية، انتقالات حالة الطلب والمخزون، تقييم الخطورة، كلمات السر والجلسات، الحماية من حقن CSV، تشفير HTML في البريد، و SEO.
- **Lighthouse (نسخة الإنتاج محلياً):**
  - **على الحاسوب:** 99–100 في كل المحاور.
  - **على الهاتف:** إمكانية الوصول وأفضل الممارسات و SEO = 100، والأداء 77–84. الأداء على الهاتف يتأثر بتشغيل React على هاتف محاكى ضعيف، ويتحسن عادة على شبكة CDN مثل Vercel.
- **الأمان:**
  - **المدخلات والأسعار:** كل المدخلات يتحقق منها الخادم (Zod)، والأسعار يعيد حسابها الخادم دائماً.
  - **قاعدة البيانات:** استعلامات Prisma محمية من حقن SQL.
  - **الجلسات وكلمات السر:** كلمات السر مشفّرة بـ scrypt، والجلسات موقّعة (HMAC) في cookie محمي (httpOnly)، ومحاولات الدخول محدودة.
  - **الحماية من CSRF:** Server Actions تتحقق من مصدر الطلب.
  - **Headers:** nosniff و X-Frame-Options و Referrer-Policy و Permissions-Policy و HSTS.
  - **الأسرار:** كلها في `.env` فقط، وكل ملفات `.env*` مستثناة من Git ما عدا `.env.example`.
